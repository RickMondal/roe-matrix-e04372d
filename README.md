# ROE Project Folder

This project demonstrates a multi-platform matrix build in GitHub Actions and stores build outputs under `ROE/builds/`.

- Matrix dimensions: OS (Ubuntu, macOS, Windows) x Python (3.9, 3.10, 3.11)
- Each job step with identifier: `matrix-e04372d`
- Artifacts uploaded via `actions/upload-artifact@v4` with prefix: `build-e04372d-`
